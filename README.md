# អង្គរ: ដំណើរផ្សងព្រេង (Angkor: The Adventure)

ហ្គេម 3D បែបខ្មែរ មើលពីក្រោយតួអង្គ (Third-person ដូច GTA) ដែលដំណើរការលើ Browser ដោយផ្ទាល់។
ហ្គេមនេះសរសេរដោយ HTML5, JavaScript និង Three.js ហើយមានម៉ាស៊ីនមេ Node.js + Socket.io សម្រាប់លេងជាមួយមិត្តភក្តិ។

---

## ១. អ្វីដែលមានក្នុងហ្គេម

**ទីក្រុងខ្មែរ បុរាណ + ទំនើប**
- ប្រាសាទអង្គរវត្ត មានគូទឹក ស្ពានថ្ម រោងព័ទ្ធជុំវិញ ថ្នាក់បី និងប្រាង្គប្រាំ (លោតឡើងដល់ជាន់កំពូលបាន)
- វិមានឯករាជ្យ នៅកណ្ដាលផ្លូវរង្វង់
- ផ្សារធំថ្មី (ដំបូលមូល) និងតូបលក់ដំបូលឆ្នូតក្រហម-មាស
- ភូមិខ្មែរ មានផ្ទះឈើខ្ពស់ ដំបូលពីរជាន់ និងដើមត្នោត
- ទីក្រុងទំនើប មានអគារខ្ពស់ៗ
- ផ្លូវធំៗ (ផ្លូវក្រវ៉ាត់ មហាវិថី) ទន្លេ វាលស្រែ ព្រៃ ប្រាសាទបាក់បែក និងភ្នំតូច

**តួអង្គខ្មែរ**
- ជ្រើសរើស ប្រុស ឬ ស្រី
- ប្រុស៖ សំពត់ចងក្បិន អាវ និងក្រមា
- ស្រី៖ សំពត់ហូល ស្បៃ និងសក់បួង
- សម្លៀកបំពាក់មាន ៣ ពណ៌ ហើយអាវុធមាន ដាវ ឬ កាំបិត

**របៀបលេងទាំង ៥**

| របៀប | ការពិពណ៌នា |
|---|---|
| ប្រយុទ្ធ (Combat) | ប្រយុទ្ធជាមួយចោរជារលកៗ។ រៀងរាល់រលកទី ៥ មានមេចោរ។ |
| ផ្សងព្រេង (Adventure) | តាសុខ អ្នកនិទានរឿង ផ្ដល់តម្រុយ ដើម្បីស្វែងរកកំណប់ ៥។ កំណប់នីមួយៗនិទានរឿងព្រេងខ្មែរមួយ៖ ព្រះថោង នាងនាគ, ចៅក្រមទន្សាយ, នាងកង្រី, តាដំបងក្រញូង និងប្រាសាទអង្គរវត្ត។ |
| បេសកកម្ម (Missions) | ជួយអ្នកភូមិប្រមូលបាវស្រូវ, ដឹកជញ្ជូនទំនិញក្នុងពេលកំណត់, និងការពារទ្វារប្រាសាទពីចោរ ៣ រលក។ |
| ប្រណាំង (Racing) | ប្រណាំងម៉ូតូ ឬរថយន្ត តាមផ្លូវក្រវ៉ាត់ក្នុងក្រុង ឬប្រណាំងទូកងតាមដងទន្លេ ជាមួយគូប្រកួត AI ៣ (២ ជុំ)។ |
| ពហុអ្នកលេង (Multiplayer) | អ្នកលេង ២ ទៅ ៤ នាក់ ដើរលេង ជជែក និងប្រកួតដាវជាមួយគ្នា តាម LAN ឬ Online។ |

**ផ្សេងៗទៀត**
- HUD បង្ហាញ ជីវិត ថាមពល ប្រាក់ (៛) ផែនទីតូច ល្បឿន និងគោលដៅ
- អាចទិញនំបញ្ចុក (បន្ថែមជីវិត) និងទឹកអំពៅ (បំពេញថាមពល) នៅផ្សារ
- ជិះម៉ូតូ បើករថយន្ត ឬជិះទូកង ក្នុងពិភពលោកបានគ្រប់ពេល (ចុច E)
- UI ពីរភាសា៖ ខ្មែរ និង English
- តន្ត្រីបែបពិណពាទ្យ (រនាត គងវង់ ស្គរ ឈិង) និងសំឡេងបរិស្ថាន បង្កើតដោយកូដ តាមរយៈ Howler.js — មិនត្រូវការឯកសារសំឡេងទេ
- ម៉ូដែល Low-poly ទាំងអស់ បង្កើតពីរូបរាងធរណីមាត្រ (មិនត្រូវការឯកសារ 3D ទេ)

## ៣. របៀបដំណើរការ

### ក. លេងម្នាក់ឯង (មិនចាំបាច់មាន Server)
បើកឯកសារ `public/index.html` ដោយផ្ទាល់ក្នុង Chrome, Edge ឬ Firefox។
កុំព្យូទ័រត្រូវភ្ជាប់អ៊ីនធឺណិត ព្រោះ Three.js, Howler.js, Socket.io និងពុម្ពអក្សរខ្មែរ ត្រូវបានទាញពី CDN។

### លេងលើទូរស័ព្ទ
បើកហ្គេមក្នុង Chrome ឬ Safari លើទូរស័ព្ទ ហើយបង្វិលទូរស័ព្ទផ្ដេក។ ហ្គេមនឹងបង្ហាញឧបករណ៍បញ្ជាសម្រាប់អេក្រង់ប៉ះដោយស្វ័យប្រវត្តិ៖
- **ខាងឆ្វេង៖** ប៉ះ ហើយអូស joystick ដើម្បីដើរ (អូសឲ្យអស់ = រត់)។ ពេលបើកបរ joystick ប្រើសម្រាប់បើកបរ និងបត់។
- **ខាងស្ដាំ៖** អូសម្រាមដៃលើអេក្រង់ ដើម្បីបង្វិលកាមេរ៉ា។
- **ប៊ូតុង៖** វាយ, លោត (ពេលបើកបរ = ហ្វ្រាំង), រត់, E (ភ្លឺពេលមានអ្វីអាចធ្វើបាន), អាវុធ, ពេញអេក្រង់, ផ្អាក និងជជែក (ពហុអ្នកលេង)។

ក្នុង LAN ទូរស័ព្ទបើកអាសយដ្ឋាន `http://<IP កុំព្យូទ័រ>:3000` ដែល Terminal បង្ហាញ ហើយអាចលេងពហុអ្នកលេងជាមួយកុំព្យូទ័របាន។

### ដំឡើងជា App លើទូរស័ព្ទ
ហ្គេមនេះជា App លើ Home Screen (PWA)។ ពេលដាក់លើ GitHub Pages រួច សូមបើកតំណ `https://vannda-yoeurn.github.io/angkor-adventure/`៖
- **Android (Chrome)៖** ចុច ⋮ → «Add to Home screen» ឬ «Install app»
- **iPhone (Safari)៖** ចុចប៊ូតុង Share → «Add to Home Screen»

App នឹងមាន icon ប្រាសាទអង្គរ បើកពេញអេក្រង់ បង្វិលផ្ដេក ឬបញ្ឈរបាន ហើយបន្ទាប់ពីបើកម្ដង អាចលេងបានទោះគ្មានអ៊ីនធឺណិតក៏ដោយ (លើកលែងតែពហុអ្នកលេង)។
ចំណាំ៖ App នៅលើ GitHub Pages (https) មិនអាចភ្ជាប់ទៅ Server ក្នុង LAN (http) បានទេ។ សម្រាប់ពហុអ្នកលេងក្នុង LAN សូមបើកតាមអាសយដ្ឋាន Server ផ្ទាល់។

### ខ. ដំណើរការជាមួយ Server (ចាំបាច់សម្រាប់ពហុអ្នកលេង)
1. ដំឡើង **Node.js 18** ឬថ្មីជាងនេះ ពី <https://nodejs.org>
2. បើក Terminal (ឬ Command Prompt) ក្នុងថតហ្គេមនេះ រួចវាយ៖
   ```bash
   npm install
   npm start
   ```
3. បើក Browser ទៅកាន់ <http://localhost:3000>

### គ. លេងជាមួយមិត្តភក្តិតាម LAN (Wi-Fi តែមួយ)
1. ដំណើរការ `npm start` នៅលើកុំព្យូទ័រមួយ។ Terminal នឹងបង្ហាញអាសយដ្ឋាន LAN ឧទាហរណ៍ `http://192.168.1.10:3000`
2. មិត្តភក្តិបើកអាសយដ្ឋាននោះនៅលើកុំព្យូទ័ររបស់ពួកគេ
3. អ្នកលេងគ្រប់គ្នាជ្រើសរើស **ពហុអ្នកលេង** ហើយវាយឈ្មោះបន្ទប់ដូចគ្នា (លំនាំដើម `angkor`) រួចចុច **ភ្ជាប់**
4. បើមិត្តភក្តិភ្ជាប់មិនបាន សូមអនុញ្ញាត Port 3000 នៅក្នុង Firewall របស់កុំព្យូទ័រដែលដំណើរការ Server

### ឃ. លេងតាម Online
- ដាក់ថតនេះទាំងមូលលើសេវា Hosting ដែលគាំទ្រ Node.js (ឧ. Render, Railway, Fly.io) ដោយកំណត់ពាក្យបញ្ជា start ជា `npm start`។ Server ប្រើ `process.env.PORT` ដោយស្វ័យប្រវត្តិ។
- ឬសាកល្បងរហ័សដោយប្រើ ngrok៖ `ngrok http 3000` រួចចែករំលែកតំណ https ដែលវាផ្ដល់ឲ្យ។

## ៥. ការកែប្រែ និងពង្រីកហ្គេម

- **ប្ដូរពណ៌សម្លៀកបំពាក់**៖ កែ `OUTFITS` ក្នុង `game.js`
- **កម្លាំងអាវុធ**៖ កែ `WEAPONS` (dmg, range, cd) ក្នុង `game.js`
- **ល្បឿនយានជំនិះ**៖ កែ `VSPEC` ក្នុង `game.js`
- **ផ្លូវប្រណាំង**៖ កែចំណុច `ROUTES.city` ឬ `ROUTES.river` ក្នុង `game.js`
- **ភាសា**៖ អត្ថបទទាំងអស់ស្ថិតក្នុង `DICT.km` និង `DICT.en` នៃ `main.js`
- **ចំនួនអ្នកលេង**៖ កែ `MAX_PLAYERS` ក្នុង `server.js`

## English summary

**Angkor: The Adventure** is a low-poly, third-person Khmer adventure game for the browser, built with Three.js, Howler.js and Socket.io. It has five modes (Combat, Adventure, Missions, Racing and Multiplayer), a Khmer/English UI, and procedurally generated pinpeat-style music, so no asset files are needed.

- **Single player:** open `public/index.html` in a modern browser (internet needed for the CDNs).
- **Server and multiplayer:** run `npm install` and then `npm start`, and open <http://localhost:3000>. Friends on the same network open the LAN address printed in the terminal. A room holds 2–4 players.
